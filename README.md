Medical Insurance Charges Prediction using Linear Regression | Python, Pandas, NumPy &amp; Scikit-learn | Data Cleaning, EDA, and Model Evaluation.
# 🏥 Insurance Charges Prediction | Linear Regression

## 🎯 Problem Statement

Insurance companies need to estimate customer insurance charges based on factors such as age, BMI, smoking status, medical history, hospital expenditure, and annual salary. Incorrect estimates can affect pricing and financial planning.

## 💡 What Problem Did I Solve?

I developed a **Machine Learning model using Linear Regression** to predict insurance charges from customer data. The project focuses on preparing historical data, identifying important patterns, and estimating charges for new customers.

## 🛠️ Tools & Technologies

* Python
* Pandas & NumPy
* Matplotlib & Seaborn
* Scikit-learn
* Linear Regression

## ⚙️ Project Workflow

1. **Data Cleaning:** Checked missing values and duplicate records.
2. **EDA:** Explored the dataset and identified outliers using boxplots.
3. **Data Preprocessing:** Handled missing numerical values using the median, removed selected outliers using the IQR method, and encoded categorical variables.
4. **Model Building:** Split the data into 80% training and 20% testing sets.
5. **Prediction:** Trained a Linear Regression model to predict insurance charges.
6. **Evaluation:** Used R² Score, MAE, MSE, and RMSE to evaluate model performance.

## 📊 Key Outcome

Built a regression model to estimate insurance charges and compare actual versus predicted values. Model performance is evaluated using regression metrics.

## 🚀 Business Value

* Supports data-driven insurance charge estimation.
* Helps analyze the relationship between customer characteristics and insurance costs.
* Demonstrates an end-to-end machine learning workflow, from data cleaning to model evaluation.

## 📌 Conclusion

This project strengthened my practical skills in data preprocessing, exploratory data analysis, Linear Regression, and model evaluation.
